A program that writes one text to `/output/entry.txt`: a one-line joke about working beside AI coding agents, set in a live demo room. An AI judge compares the jokes pairwise; the 20 best win rates share $35.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat out/entry.txt
```

The program is deterministic (Python 3.13, stdlib only, no network) and writes the same joke on every run.
